# SchoolFlow — финальное обновление перед защитой

## Что изменено
1. Раздел «Ещё»: карточная сетка ссылок, крупные зоны нажатия, адаптация под телефон.
2. Список заявок: явная кнопка «Открыть» и кликабельное описание, в том числе для администратора. Просмотр полной карточки доступен администратору; назначение — отдельная кнопка.
3. «Склад» убран из меню и интерфейса. Данные таблицы inventory не удаляются из SQLite. Старые API склада пока оставлены для обратной совместимости: для полного удаления потребуются отдельная миграция и пересмотр тестов.
4. Регистрация учителей в production (`DEMO_MODE=0`) — только по одноразовому приглашению администратора. Приглашение действует 7 суток, хранится только SHA-256 от кода, повторно не используется. Для локального DEMO_MODE=1 оставлен демонстрационный режим, не используйте его публично.
5. Управление → «Доступ учителей» → «Создать код учителю». Код показывается только после выпуска; его нужно передать конкретному учителю. Не публикуйте его открыто.

## Как обновить действующий Railway
1. Сначала создайте резервную копию подключённого Volume `/data`. Убедитесь, что копия реально доступна.
2. В GitHub замените файлы нового архива, не загружайте старую базу `.db`, папку `uploads`, `.env` и секреты.
3. Убедитесь, что на Railway `DEMO_MODE=0` и `SCHOOL_PLUS_DATA_DIR=/data`. Остальные значения не изменяйте.
4. Дождитесь успешного автоматического Deploy. Приложение само создаст новую таблицу приглашений; существующие аккаунты и заявки останутся.
5. Войдите администратором, откройте раздел «Управление», создайте приглашение. Проверьте регистрацию учителя по коду, его повторное использование должно быть запрещено.
6. Создайте тестовую заявку учителя и проверьте открытие через «Заявки → Открыть» у администратора.

## Перед защитой
- Проверьте на телефоне меню «Ещё», таблицы заявок и страницу входа; мобильный браузер здесь не тестировался.
- Убедитесь, что у всех демонстрируемых ролей есть аккаунты: открытая регистрация работников отключена.
- Для критических ситуаций ИИ только рекомендует действия; реальная эвакуация регулируется планом школы и решениями ответственных людей. Уведомления пока только внутри системы, не SMS и не школьная сирена.
- Не демонстрируйте реальные персональные данные детей или сотрудников. Не показывайте секреты Railway.
