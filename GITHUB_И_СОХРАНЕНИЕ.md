# ШКОЛА+ — аккаунты и GitHub

## Как хранятся аккаунты

Регистрация записывает нового пользователя в SQLite (`school_plus.db`) через `INSERT` и `commit`.
Пароль сохраняется как PBKDF2-хеш, а не открытым текстом. После закрытия браузера и
перезапуска сервера пользователь может снова войти со своим логином и паролем.
Также сохраняются заявки, статусы и другая информация.

По умолчанию база находится в `backend/school_plus.db`. **Не удаляйте этот файл**, если
хотите сохранить аккаунты. Для хостинга рекомендуется задать `SCHOOL_PLUS_DATA_DIR`
в `backend/.env`, например `SCHOOL_PLUS_DATA_DIR=C:/school-plus-data` на Windows,
или в переменных окружения сервера. Эта папка должна находиться на постоянном диске.
В неё также будут записаны фотографии и секрет сессий.

**Важно:** GitHub сохраняет код, но НЕ аккаунты: база специально исключена из Git.
Чтобы несколько компьютеров использовали одни аккаунты, они должны обращаться к
**одному запущенному серверу** (например, через `start_lan.bat` в локальной сети
или через сервер с постоянным хранилищем). GitHub Pages не поддерживает этот Python API.

## Как проверить сохранение вручную

1. Запустите `start.bat`, откройте http://127.0.0.1:8000.
2. Зарегистрируйте учителя с новым логином и паролем (от 6 символов).
3. Выйдите из аккаунта. Остановите сервер и снова запустите `start.bat`.
4. Войдите под новым логином и паролем. Учётная запись должна открыться.
5. Для копии базы и фотографий запустите из папки `backend`:
   `python backup.py` (в активном виртуальном окружении).

## Загрузка на GitHub через браузер

1. Войдите в https://github.com/new и создайте репозиторий `school-plus`.
2. Для первого добавления можно использовать GitHub Desktop — это надёжнее,
   чем вручную загружать папки в веб-интерфейсе.
3. В GitHub Desktop выберите **File → Add local repository**. Если папка ещё
   не Git-репозиторий, выберите **Create a Repository** и укажите папку `school_work`.
4. Создайте коммит, нажмите **Publish repository**. Для школьного проекта
   лучше начать с **Private**, а сделать публичным уже после проверки.
5. Проверьте на GitHub, что нет `.env`, `.secret`, `school_plus.db`, папок
   `uploads`, `backups` и личных данных учеников.

## Git в терминале (в папке `school_work`)

```bash
git init
git add .
git status
git commit -m "School Plus: persistent accounts and deployment preparation"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/school-plus.git
git push -u origin main
```

Заранее создайте пустой репозиторий `school-plus` на GitHub. GitHub может потребовать
авторизацию через браузер или токен, а не пароль.

## Если хотите открыть сайт в интернете

**GitHub != хостинг сервера.** Для онлайн-регистрации нужен хостинг FastAPI/uvicorn
с постоянным диском (или отдельной управляемой БД). У хостингов с временным диском
аккаунты могут исчезать после деплоя или рестарта. Настройте `DEMO_MODE=0`,
надёжный `SCHOOL_PLUS_SECRET` и HTTPS. Для показа в классе проще использовать
локальный сервер и `start_lan.bat`.
