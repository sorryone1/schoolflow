# SchoolFlow V3 — регистрация и меню «Ещё»

## Изменения
- Регистрация: имя, логин, пароль; никаких кодов и выбора роли.
- Новый аккаунт получает `approved=0`, не получает токен и не может войти, пока администратор не подтвердит.
- Администратор: Управление → Пользователи → выберите роль → Подтвердить. Допускаются учитель, работник, директор.
- Существующие аккаунты остаются активными (`approved=1` по умолчанию).
- Сохранены все заявки, уведомления, функции ИИ, PDF, серверные маршруты кроме устаревших маршрутов приглашений. Старая таблица `teacher_invites` оставлена без удаления данных.
- Вкладка «Ещё» открывает отдельную страницу с адаптивными плитками, вместо кривого всплывающего окна.

## Обновление Railway
1. Скопируйте Volume `/data` (база и фотографии) во внешнюю резервную копию перед публикацией.
2. Обновите файлы репозитория из ZIP, сохранив `.git` при использовании GitHub Desktop. Не загружайте `school_plus.db`, `.env`, `uploads` и пароли.
3. Выполните Commit и Push. Railway автоматически развернёт новый код. **Volume не удалять**.
4. Проверьте админ-вход, предыдущие заявки, новую регистрацию, запрет входа до подтверждения, затем назначение роли и вход, меню «Ещё» на телефоне и компьютере.

## Известные ограничения
Не проверено визуально на реальных мобильных браузерах. Открытая форма регистрации может создавать спам-заявки на подтверждение; перед полноценным внедрением потребуются лимиты частоты регистрации и/или CAPTCHA. Новых администраторов из публичной регистрации создавать нельзя.
