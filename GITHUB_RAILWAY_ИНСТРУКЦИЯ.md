# ШКОЛА+ — публикация в GitHub и Railway

## 1. GitHub
1. Создайте **Private** repository `school-plus` на https://github.com/new (приватный — пока не проверена безопасность публичного продукта).
2. Распакуйте ZIP. Загрузите **содержимое** папки `school_work` в корень репозитория, а не сам архив. В GitHub: `Add file` → `Upload files` → `Commit changes`.
3. Проверьте, что корневая папка репозитория содержит `Dockerfile`, `backend/`, `frontend/`, `railway.json`.
4. Не загружайте `.env`, `school_plus.db`, `uploads/` или пароли/API-ключи.

## 2. Railway
1. Откройте https://railway.com/ и войдите с помощью GitHub.
2. `New Project` → `Deploy from GitHub repo` → `school-plus`.
3. В созданном сервисе: `Settings` → `Volumes` → `Add Volume`: mount path **`/data`**. База и фотографии должны храниться именно в этом томе. Не публикуйте сайт, пока том не подключён.
4. `Variables`: добавьте настройки, перечисленные ниже. Примените изменения и запустите новый deploy.
5. `Settings` → `Networking` → `Generate Domain`. Получите ссылку вида `https://...up.railway.app`.
6. Откройте адрес `/api/health`: ожидается `{"ok":true,...}`. Откройте главную страницу, зарегистрируйте учителя, проверьте вход.

## 3. Переменные Railway
- `DEMO_MODE` = `0`
- `SCHOOL_PLUS_DATA_DIR` = `/data`
- `SCHOOL_PLUS_ADMIN_LOGIN` = придумайте уникальный логин администратора
- `SCHOOL_PLUS_ADMIN_PASSWORD` = придумайте **уникальный длинный пароль (12+ символов)**; не публикуйте его
- `SCHOOL_PLUS_SECRET` = случайный секрет (32+ байт, например результат Python `secrets.token_urlsafe(48)`). Храните неизменным.
- `ALLOW_WORKER_SIGNUP` = `0` (работников создаёт администрация, если функция предусмотрена интерфейсом).
- Необязательно: `DARKAPI_API_KEY` = действующий ключ совместимого API (если нужен ИИ).

**Важно:** исходный код создаёт администратора из этих переменных лишь когда администратора ещё нет. Не меняйте его пароль только через переменные: это не сброс пароля.

## 4. Проверка сохранения
1. Зарегистрируйте учителя с новым логином.
2. Войдите, создайте тестовую заявку.
3. В Railway вручную нажмите `Redeploy` / `Restart`.
4. Повторно войдите с тем же логином и проверьте, что заявка осталась.

## 5. Что важно помнить
- GitHub **хранит код**, Railway **исполняет сервер**, а Railway Volume **хранит SQLite и загруженные фотографии**.
- Railway может быть платным: проверьте актуальную стоимость и лимиты аккаунта перед активацией.
- Сделайте резервные копии содержимого `/data`: постоянный том не заменяет бэкап.
- Не публикуйте реальные персональные данные школьников до проверки соответствия требованиям школы и правилам защиты данных.
- Приложение работает с **одним серверным процессом** (`--workers 1`) и локальным SQLite; не увеличивайте число экземпляров без миграции на серверную БД.
- Регистрация учителей доступна пользователям; регистрация работников в публичном режиме отключена намеренно.
