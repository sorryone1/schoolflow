# SchoolFlow

Школьная система заявок на ремонт. Включает интерактивный план этажей, QR-коды кабинетов, учёт сроков, аналитику и отчёты. Сервер работает на FastAPI и SQLite, интерфейс использует HTML, CSS и JavaScript.

## Локальный запуск

На Windows запустите `start.bat` и откройте <http://127.0.0.1:8000>. Для доступа с другого устройства в школьной сети используйте `start_lan.bat` и IP-адрес компьютера с портом 8000.

На Linux или macOS из корня репозитория:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload
```

Для локальной демонстрации доступны пользователи `teacher`, `worker`, `admin` и `director` с паролем `1234`. Тестовые заявки можно создать в кабинете администратора через «Управление».

## Railway

Разверните репозиторий через Dockerfile, подключите постоянный том по пути `/data` и проверьте `/api/health`. Запускайте один экземпляр сервиса. Укажите переменные окружения:

| Переменная | Значение |
| --- | --- |
| `DEMO_MODE` | `0` |
| `SCHOOL_PLUS_DATA_DIR` | `/data` |
| `SCHOOL_PLUS_ADMIN_LOGIN` | Логин первого администратора |
| `SCHOOL_PLUS_ADMIN_PASSWORD` | Пароль первого администратора длиной от 12 символов |
| `SCHOOL_PLUS_SECRET` | Постоянный случайный секрет JWT. Если переменная пуста, сервер хранит сгенерированный секрет в `/data/.secret` |

Переменные логина и пароля используются при создании первого администратора. После заполнения формы регистрации новый пользователь получает доступ, когда администратор подтвердит учётную запись и назначит роль.

## Анализ фотографий

Для локальной настройки создайте `backend/.env`. На Railway задайте те же значения в настройках сервиса. Для DarkAPI используются `DARKAPI_API_KEY`, `DARKAPI_BASE_URL` и `DARKAPI_MODEL`. Для OpenAI используйте `OPENAI_API_KEY`, `OPENAI_BASE_URL=https://api.openai.com/v1` и `OPENAI_MODEL` с поддержкой изображений. Заявки принимаются и без ключа. Результаты анализа предварительные. Решение о безопасности принимает ответственный специалист.

## Данные и резервные копии

Локально база SQLite, фотографии и сгенерированный секрет хранятся в `backend/`. На Railway эти файлы хранятся в постоянном томе. Для резервного копирования запустите `python backend/backup.py` с тем же `SCHOOL_PLUS_DATA_DIR`, что и у приложения. Скрипт сохраняет базу и фотографии в `backups/` внутри каталога данных. Храните копию отдельно от рабочего тома.

## Проверки

Установите `httpx` в окружение проекта, затем запускайте каждый файл из `tests/` отдельным процессом с временным каталогом данных:

```sh
python -m pip install httpx
for test in tests/test_*.py; do
  SCHOOL_PLUS_DATA_DIR="$(mktemp -d)" python "$test" || break
done
```

Для проверки PDF нужен шрифт DejaVu Sans по пути `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`. Dockerfile устанавливает его автоматически.
