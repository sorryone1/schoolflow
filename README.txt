ШКОЛА+ — система заявок и контроля школьной инфраструктуры
==========================================================

ЗАПУСК
  1. Запустите start.bat (первый раз он сам создаст окружение и поставит зависимости).
  2. Откройте http://127.0.0.1:8000
  Для телефонов и QR-кодов: start_lan.bat, затем откройте систему по адресу компьютера
  в школьной сети (узнать: ipconfig), например http://192.168.1.5:8000
  Ключ ИИ — в backend/.env (по образцу .env.example). Без ключа всё работает, только
  без анализа фото.

ДЕМО-ДОСТУП (пароль 1234):  teacher · worker · admin · director
  На экране входа есть кнопки быстрого входа. Раздел «Сценарий защиты» ведёт по шагам
  демонстрации и переключает роли одной кнопкой.
  Перед показом: войти администратором → Управление → «Добавить демо-данные»
  (16 заявок, чтобы заработали аналитика и тепловая карта).

ВОЗМОЖНОСТИ
  • План школы: схема этажей с состоянием кабинетов и тепловая карта проблем за 30 дней.
  • Заявки: список с фильтрами и поиском, канбан-доска, живые таймеры SLA.
  • Форма заявки: выбор кабинета, предупреждение о дубликатах, фото с предпросмотром.
  • QR-код кабинета: сканирование открывает форму заявки именно для этого кабинета.
  • ИИ-анализ фото (если задан ключ): проблема, инструменты, материалы, безопасность.
  • Аналитика: реакция, ремонт, SLA, категории, этажи, исполнители; выгрузка в CSV.
  • Роли: учитель, работник, администратор, директор — у каждого свой набор прав.
  • Палитра команд (Ctrl+K или «/»), светлая/тёмная тема, плотный режим, печать QR.

БЕЗОПАСНОСТЬ
  • Токен передаётся заголовком Authorization, а не в адресе.
  • Фото отдаются только участникам заявки; обход путей к .env закрыт.
  • Секрет JWT, если в .env заглушка, создаётся автоматически (backend/.secret).
  • Заголовки CSP/nosniff/no-referrer, ограничение попыток входа, пароль от 6 символов.
  • Регистрацию работников можно отключить: ALLOW_WORKER_SIGNUP=0 в backend/.env.

СТРУКТУРА
  backend/main.py            API (FastAPI + SQLite), ИИ-анализ, права, SLA, CSV
  frontend/index.html        оболочка
  frontend/assets/core.js    безопасные шаблоны, API, роутер, оболочка, таймеры
  frontend/assets/views.js   все экраны и действия
  frontend/assets/boot.js    запуск
  frontend/assets/styles.css базовые стили (светлая/тёмная темы, адаптив, печать)
  frontend/assets/simple.css «простой дизайн»: крупный текст, большие кнопки, карточки.
                             Чтобы вернуть прежний вид, уберите его строку в index.html
